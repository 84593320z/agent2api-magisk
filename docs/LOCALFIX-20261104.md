# agent2api 本地修复重打包（localfix-20261104）

## 这是什么

在官方 `v3.3.0-beta.7 (magisk.32)` 脚本基线上，对本机 `agent2api` 模块做全面
安全/稳定性修复后的**纯脚本重打包**。不含服务端载荷（payload 与插件不在包内，
由模块更新器独立管理），刷新本包不会降级载荷版本。

## 安装方式

- 管理器（KernelSU / Magisk App）刷入本 zip：`customize.sh` 会检测到现有安装，
  把脚本原子复制进模块目录并调用 `hotinstall.sh` 后台热重启服务，**免重启手机**。
- 刷入后几秒内服务自动重启完成；也可随时 `a2a restart` 或重启手机，效果一致。
- 全新安装（模块目录不存在）时本包只提示不做热应用——请先刷官方完整包。

## 修复内容（14 项 + 复审追加 8 项）

更新事务：先停服后切换、数据快照与回滚（backup/data-prev）、txid 代次绑定提交、
停服状态更新的"未验证"独立状态、`a2a rollback --with-data`。
cgroup：全控制器解析 + mountinfo 定位挂载根 + 迁移回读核验，control/supervise/
hot-restart 三个拉起路径全覆盖（根治 App cgroup 后台冻结）。
启动：boot-worker 统一开机入口（boot_delay/net_wait/autostart 对两条钩子全部生效）、
恢复逻辑证据驱动并移入实例锁后、hot-restart 请求文件 + 单 worker。
卸载：停止失败即中止零删除、强化停止覆盖 supervisor/server/插件/worker、
purge 仅在全部进程确认退出后执行。
DNS：全候选失败按初始状态三态精确还原、恢复结果读回校验。
安全：镜像 SHA 信任降级默认关闭（update_sha_via_mirror=0）、WebUI 全 DOM+
textContent 渲染、状态 JSON 转义、wget 回退仅在 update_pin 时允许。

## 重要说明

- **官方更新（在线更新或刷官方 zip）会覆盖本包的全部修复**，届时重新刷回本包即可；
  也可从 `/data/adb/agent2api/backup/scripts-fix-20261104-000418/` 恢复原始基线。
- 本包与官方包的 `version`/`versionCode` 保持一致，不影响更新检查行为；
  修复标识仅体现在本文件与安装横幅中。
- 设备侧运行时配置（`/data/adb/agent2api/etc/settings.conf`）不在包内，
  刷入不会覆盖任何已有配置、数据与载荷。
