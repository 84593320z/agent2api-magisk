服务端跑在本机。面板端口可能与网关端口不同（见 panel_port），这个页面只是块"指路牌"。

打开面板

如果是从电脑访问，把 127.0.0.1 换成手机局域网 IP。

数据来自模块目录 webroot/status.json 与 webroot/lastlog.txt，5 秒刷新；守护进程没起来时读不到属正常。

常用命令（需 root shell）

sh /data/adb/agent2api/bin/a2a status      # 运行状态
sh /data/adb/agent2api/bin/a2a doctor      # 全项体检
sh /data/adb/agent2api/bin/a2a logs        # 看日志
sh /data/adb/agent2api/bin/a2a update      # 在线升级到最新版
sh /data/adb/agent2api/bin/a2a rollback    # 升级失败回滚
sh /data/adb/agent2api/bin/a2a restart     # 重启服务端
配置在 /data/adb/agent2api/etc/settings.conf，改完 a2a restart 生效。

首次使用

  1. 打开面板，注册管理员账号（第一个注册的人就是管理员）
  2. 在面板里配置上游账号、生成 API Key
  3. 客户端把 Base URL 指向 http://手机IP:3065/v1
